# 评测集说明

两份数据集，**一份对内、一份对外**，用途不同，不要混引。

| 文件 | 题量 | 用途 |
|---|---|---|
| `qa.jsonl` | 20 题 + 3 拒答陷阱 | **内部回归集**：调参、消融、索引 A/B 都用它 —— 题多、覆盖细，适合看「改动有没有副作用」 |
| `qa_formal10.jsonl` | **10 题**（3 道跨公司题 + 2 道拒答陷阱） | **正式评测集**：课程作业的正式结论只引这一份 |

两份的题干与 `gold_chunk_ids` **逐字相同** —— `qa_formal10.jsonl` 是从 `qa.jsonl`
按 qid 筛出来的，不存在两份手抄造成的漂移。

## 正式 10 题是怎么选的

选取原则：五个题型全覆盖；跨公司题 3 道（要求 ≥2）；保留最难的几道；保留 2 道拒答陷阱。

| qid | 类型 | 考点 |
|---|---|---|
| Q01 | 单点数值 | 联影医疗营收。★旗舰题：正文索引下 BM25 全库 #795 / 向量 #541，两路都召不回 |
| Q04 | 单点数值 | 拱东医疗营收。**单位是万元**，考口径（答成「元」即为错） |
| Q06 | 同比与原因 | 联影现金流同比 + 原因。数字在表格块、原因在正文块，需跨块作答 |
| Q08 | 同比与原因 | 天智航研发占比为何上升。★原因段的**标题与内容不符**（标题写「非经常性损益」） |
| Q11 | 跨公司对比 | 联影 vs 心脉 营收，哪家更高 |
| Q13 | 跨公司对比 | 赛诺 vs 三友 归母净利润同比，哪家更好 |
| Q15 | 跨公司对比 | 心脉 vs 惠泰 研发投入占比。★两家都必须取「财务指标表」而非会计数据表 |
| Q16 | 条件筛选 | 17 家里归母净利润同比下降的有哪几家（gold 9 条 > Top-6，recall 天然有上限） |
| T01 | 拒答陷阱 | 问 2026 **第三季度**营收 —— 半年报只覆盖 1－6 月，必须拒答 |
| T03 | 拒答陷阱 | 爱博诺德归母净利润 —— 该行被 PDF 抽取丢掉（全库 0 命中），必须拒答 |

未被选中的 12 题（Q02 / Q03 / Q05 / Q07 / Q09 / Q10 / Q12 / Q14 / Q17 / Q18 / Q19 /
Q20 / T02）留在 `qa.jsonl` 里继续做内部回归 —— 它们仍然有效，只是不进正式结论。

## 每题字段

```json
{"qid": "Q01", "type": "单点数值", "question": "...", "company": ["688271"],
 "gold_chunk_ids": ["688271-0009"], "gold_answer": "...", "note": "...",
 "split": "formal"}
```

- `gold_chunk_ids`：**逐条打开原文核对过**，`note` 里写了核对命令与页码
- `gold_answer`：标准答案，含口径与单位（列在 `note` 里的是核对要点）
- `note`：页码、跨块说明、以及这道题设计的**陷阱在哪**
- `split`：仅正式集有
